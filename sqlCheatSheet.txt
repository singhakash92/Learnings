Q) GROUP BY - find all unique (col1, col2, coln) combinations now its one group
1)  SELECT customer, region, COUNT(*) as count, SUM(amount) as total
    FROM sales
    GROUP BY customer, region;

    a) Find all unique (customer, region) combinations
    John + North
    John + South
    Sarah + North
    Sarah + East
    Mike + South
    b) Apply aggregate functions to each group
    John + North  → COUNT=2, SUM=52000 (50000+2000)
    John + South  → COUNT=1, SUM=5000
    Sarah + North → COUNT=2, SUM=103000 (55000+48000)
    Sarah + East  → COUNT=1, SUM=25000
    Mike + South  → COUNT=2, SUM=63000 (48000+15000)

18) RANKING - only ORDER BY
ROW_NUMBER()
RANK()
DENSE_RANK()
ORDER BY matters because : "Based on what should I rank these rows?"

ROW_NUMBER():simply assigns a sequential number to every row.(1,2,3,4,5,6...)
SELECT
    name,
    salary,
    ROW_NUMBER() OVER(
        ORDER BY salary DESC
    ) AS row_num
FROM Employees;
    - SQL first sorts the rows: 90.000, 80.000, 80.000, 70.000, 70.0000, 60.000
    - Then assigns numbers:     1       2       3       4       5        6



A = 100
B = 90
C = 90
D = 80

ROW_NUMBER : Everyone gets a unique position:
A → 1
B → 2
C → 3
D → 4

RANK : Ties share rank, and gaps appear: 
A → 1
B → 2
C → 2
D → 4

DENSE_RANK : Ties share rank, but no gaps:
A → 1
B → 2
C → 2
D → 3

LAG
SELECT
    month,
    sales,
    LAG(sales, 1, 0) OVER(
        ORDER BY month
    ) AS previous_sales
FROM Sales;

SELECT
    month,
    department,
    sales,
    LAG(sales) OVER(
        PARTITION BY department
        ORDER BY month
    ) AS previous_sales
FROM Sales;

21) value functions
FIRST_VALUE - what's the first value in this table/group(if partition by is there)
LAST_VALUE - what's the last value in this table/group(if partition by is there)
NTH_VALUE - what's the Nth value in this table/group(if partition by is there)

FIRST_VALUE(column_name)
LAST_VALUE(column_name)
NTH_VALUE(column_name, n)

SELECT
    employee,
    department,
    salary,
    FIRST_VALUE(salary) OVER(
        PARTITION BY department
        ORDER BY salary
    ) AS highest_salary
FROM Employees;
