Q) GROUP BY - find all unique (col1, col2, coln) combinations now its one group
1)  SELECT customer, region, COUNT(*) as count, SUM(amount) as total
    FROM sales
    GROUP BY customer, region;

    a) Find all unique (customer, region) combinations
    John + North
    John + South
    Sarah + North
    Sarah + East
    Mike + South
    b) Apply aggregate functions to each group
    John + North  → COUNT=2, SUM=52000 (50000+2000)
    John + South  → COUNT=1, SUM=5000
    Sarah + North → COUNT=2, SUM=103000 (55000+48000)
    Sarah + East  → COUNT=1, SUM=25000
    Mike + South  → COUNT=2, SUM=63000 (48000+15000)


    customer | region | count | total
    ---------|--------|-------|--------
    John     | North  | 2     | 52000
    John     | South  | 1     | 5000
    Sarah    | North  | 2     | 103000
    Sarah    | East   | 1     | 25000
    Mike     | South  | 2     | 63000



7) HAVING always comes after GROUP BY
(its like applying WHERE clause but to whole group)
SELECT customer, region, COUNT(*) as count, SUM(amount) as total
    FROM sales
    GROUP BY customer, region
    HAVING SUM(amount) > 100000;

    ***columns that we use inside having follows same pattern as of select while using in group BY******

12) INNER JOIN or JOIN - returns common rows between 2 tables
    (join two table(cross product), and retains the row which are common between the table based on the specified condition )

    SELECT * 
    FROM authors
    INNER JOIN books
    ON authors.author_id = books.book_id;

12) LEFT JOIN or LEFT OUTER JOIN - common rows between 2 tables + all rows in left table
-- common rows records between two table + all records in left table
-- for a row in left , if no match exists in right table, null value will be returned for right table columns 

    SELECT c.customer_id, c.customer_name
    FROM customers c LEFT JOIN orders o ON c.customer_id = o.customer_id
    LEFT JOIN shipping s ON o.order_id = s.order_id
    -- WHERE o.order_id IS NOT NULL AND s.shipping_id IS NULL 
    GROUP BY c.customer_id


13) RIGHT JOIN or RIGHT OUTER JOIN -  common rows between 2 tables + all rows in right table
-- common rows records between two table + all records in right table
-- for a row in right , if no match exists in left table, null value will be returned for left table columns
